# Adosados de Nigrán · Visita 3D

Visita interactiva de las viviendas de las parcelas 18 y 19, reconstruida a partir de los planos facilitados.

Incluye planta baja, primera y bajo cubierta, recorrido automático y movimiento libre. Arrastra para mirar y usa W A S D, las flechas o los botones para moverte. Puedes cambiar de vivienda, planta y estancia con los selectores.

Es un modelo aproximado. Mobiliario, alturas y algunos acabados son orientativos. Los cambios de planta se realizan mediante saltos de vista.

La visita está contenida en `index.html` y se puede abrir directamente en un navegador. Para publicarla con GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Utiliza Three.js, cuya licencia MIT está incluida en su código integrado.
